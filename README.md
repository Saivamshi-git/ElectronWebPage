⚡ Electron - Beta (v1.0)
Turn your prompts into actions. This application uses advanced Semantic Automation to control your Windows desktop. By analyzing the "Accessibility Tree" (not just screenshots), it allows AI to reliably click, type, and navigate any application on your computer.

✨ Key Features
🌳 Semantic Automation: We parse UI trees into context. The AI intelligently invokes, selects, and manipulates apps to perform complex tasks based on the actual structure of the application.

🔍 Native UI Inspection: Built on FlaUI. The agent 'sees' buttons, inputs, and grids exactly how Windows renders them for maximum reliability.

🧠 Model Agnostic: Bring your own keys! We support Nvidia NIM, Groq, Gemini, Perplexity, OpenRouter, and Cohere.

💻 Console Control: Watch the agent's thought process in real-time via the built-in terminal stream inside the app.

🔒 Privacy by Design: Your API keys are stored locally on your machine. We process text-based Accessibility Trees, not constant video streams or pixel screenshots.

🛡️ Human-in-the-loop: Pause, resume, or take over control at any moment. You are always the pilot.

📥 How to Install & Run
No coding or compilation required. Just follow these steps:

Download the .zip file listed in the "Assets" section below.

Extract the folder to a location of your choice.

Open the folder and look for the application named Electron2 (or Electron2.exe).

Run the application.

Configure AI:

Inside the app, navigate to the API Plugin Page.

Select your preferred provider (Groq, Gemini, OpenAI, etc.).

Insert your API Key and Model name.

Boom! 🚀 You are ready to start automating. Just type a command and watch it work.

📋 Requirements
OS: Windows 10 or Windows 11.

Internet: Required for communicating with the AI models.
